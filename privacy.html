Datenschutzerklärung

braunhome-backup wird ausschließlich vom Betreiber für das eigene Google-Konto genutzt. Die App fordert nur die Berechtigung drive.file an und greift damit nur auf Dateien zu, die sie selbst angelegt hat. Sie lädt verschlüsselte Backups hoch und liest sie zur Wiederherstellung. Es werden keine Daten an Dritte weitergegeben, verkauft oder für andere Zwecke verwendet. Zugriffs-Tokens liegen nur auf dem Server des Betreibers.

Privacy policy

braunhome-backup is used only by its operator for their own Google account. It requests only the drive.file scope, so it can access only files it created itself. It uploads encrypted backups and reads them for restores. No data is shared with third parties, sold or used for any other purpose. Access tokens are stored only on the operator's server.
